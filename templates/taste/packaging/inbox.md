# Packaging inspiration inbox

> Where a video, thumbnail, intro or creator lands the moment it is dropped into any conversation, before any teardown runs. Verbatim, always: the link and **your exact words about why it stopped you**, because the why is the taste and the link is only the pointer. `by:` names who sent it. Each entry links to its teardown once written.
>
> A link with no reaction is half an entry. If somebody pastes a link with no words, the session files it and asks for the reaction, because that is the half that carries the taste.
>
> Teardowns live beside this file as `packaging/<slug>.md`, with thumbnails and frame sheets saved in `packaging/thumbs/` and `packaging/frames/`. Rules distilled from them go to `thumbnails.md` and `packaging.md`, never here.

## Format

```
## YYYY-MM-DD · <creator or slug> · by: <who>
link: <url>
why (verbatim): "<their words, before any analysis>"
teardown: <file, or "pending">
what it shares with the corpus: <one line, filled when the teardown lands>
```
