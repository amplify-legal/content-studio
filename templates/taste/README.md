## Rules versus guidelines

<How you mark the difference. A suggested default: a rule is something you have said twice, or said once and called a rule. A guideline is something you said once about one piece. A guideline stays a guideline until it repeats. Every entry in every file says which it is.>

## How these files change

- A correction lands in the right file **in the same session it was made**, and the session says which file it went in, in chat and in the work log.
- New rules enter only from your real feedback, dated, in your words. A machine's opinion never becomes a rule.
- A rule that turns out wrong is corrected in place with the correction visible. It is not silently deleted.
- A scoped ruling stays scoped. If you said it about one video, it says so.
